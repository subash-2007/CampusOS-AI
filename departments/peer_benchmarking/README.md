# Department 015: Peer Benchmarking (`peer_benchmarking`)

## Overview
The **Peer Benchmarking Department** delivers an enterprise multi-agent pipeline designed to calculate candidate percentile ranks, compare academic rigor, measure skill density against peer medians, index career velocity, rank open-source impact, benchmark certification rigor, and formulate peer outperformance strategies.

---

## Internal 10-Agent Architecture

### Deterministic Agents (7)
1. **CohortPercentileScorerAgent**: Calculates overall cohort percentile tier.
2. **AcademicPeerComparisonAgent**: Compares academic GPA and coursework rigor.
3. **SkillDensityBenchmarkAgent**: Measures skill count vs. peer median.
4. **ExperienceVelocityIndexAgent**: Indexes promotion frequency and progress velocity.
5. **OpenSourcePeerRankerAgent**: Ranks GitHub activity against developer benchmarks.
6. **CertificationRigorBenchmarkAgent**: Benchmarks industry certifications and prestige.
7. **PeerScorerAgent**: Master deterministic aggregator for peer metrics.

### Reasoning Agents (2)
8. **StrategicPeerNarrativeAgent**: Evaluates competitive positioning and key differentiators.
9. **PeerOutperformanceStrategistAgent**: Formulates actionable outperformance strategies.

### Orchestrator Agent (1)
10. **PeerBenchmarkingOrchestratorAgent**: Master Orchestrator Agent uniting peer metrics and strategy.
