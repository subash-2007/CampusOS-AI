# Department 007: Career Roadmap (`career_roadmap`)

## Overview
The **Career Roadmap Department** delivers an enterprise multi-agent pipeline designed to formulate 30-60-90 day milestone execution plans, calculate salary progression trajectories, map role advancement paths, break down weekly action plans, and project 5-year long-term career visions.

---

## Internal 10-Agent Architecture

### Deterministic Agents (7)
1. **MilestoneGeneratorAgent**: Formulates 30-60-90 day milestone objectives and key results.
2. **SalaryTrajectoryCalculatorAgent**: Calculates salary benchmark increases and percentage gains.
3. **RoleProgressionMapperAgent**: Maps role progression from junior to staff/executive levels.
4. **WeeklyPlanGeneratorAgent**: Breaks milestone goals down into weekly task plans.
5. **RiskMitigationAnalyzerAgent**: Identifies execution risks and mitigation strategies.
6. **FeasibilityScorerAgent**: Calculates overall roadmap feasibility index score.
7. **RoadmapScorerAgent**: Master deterministic aggregator for Career Roadmap.

### Reasoning Agents (2)
8. **StrategicCareerAdvisorAgent**: Formulates executive narratives and networking strategies.
9. **LongTermVisionStrategistAgent**: Formulates 5-year long-term career visions and pivot milestones.

### Orchestrator Agent (1)
10. **RoadmapOrchestratorAgent**: Master Orchestrator Agent uniting milestone timelines and long-term career strategy.
