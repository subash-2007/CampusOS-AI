# Department 022: Executive Communication (`executive_communication`)

## Overview
The **Executive Communication Department** delivers an enterprise multi-agent pipeline designed to measure briefing conciseness, audit executive presence tone, score board slide deck readiness, evaluate active listening traits, measure data storytelling clarity, audit crisis communication response speed, and generate C-suite executive memo drafts.

---

## Internal 10-Agent Architecture

### Deterministic Agents (7)
1. **BrevityConcisenessMeterAgent**: Measures brevity and word count efficiency in briefings.
2. **ExecutiveToneAuditorAgent**: Audits executive presence and assertiveness index.
3. **BoardDeckReadinessScorerAgent**: Scores slide deck readiness for board meetings.
4. **ActiveListeningMeterAgent**: Evaluates active listening indicators and empathy scores.
5. **DataStorytellingScorerAgent**: Scores data visualization clarity and quantitative structure.
6. **CrisisCommunicationAuditorAgent**: Audits crisis response speed and transparency.
7. **ExecutiveCommScorerAgent**: Master deterministic aggregator for executive comms metrics.

### Reasoning Agents (2)
8. **StrategicExecutiveNarrativeAgent**: Formulates C-suite presentation evaluations.
9. **ExecutiveBriefingGeneratorAgent**: Generates concise C-suite briefing memos.

### Orchestrator Agent (1)
10. **ExecutiveCommunicationOrchestratorAgent**: Master Orchestrator Agent uniting communication metrics and briefing generation.
